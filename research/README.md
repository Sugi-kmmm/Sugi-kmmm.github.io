# 研究業績の書き方

業績は **1件につき1つの .md ファイル** で，`research/<年>/` に置きます．
ファイルを追加・修正して GitHub に push すると，数分でサイトに反映されます（**HTML を書く必要はありません**）．
研究内容ページ（research.html）の一覧にも自動で載ります（年タブ・種別ごと）．

```
research/
├─ 2024/
│   ├─ 2024robomech_1.md   業績1件（URL は /research/2024/2024robomech_1.html になる）
│   └─ 2024cleo.md
├─ 2025/
│   └─ 2025_award.md       受賞
├─ _template/              ひな形（コピーして使う．サイトには表示されない）
└─ index.json              全業績の一覧（GitHub Pages が自動で作る．編集しない）
```

## 追加のしかた

1. `_template/` から種類に合うひな形をコピーし，`research/<年>/` に置く
   - 論文・会議発表・解説など → `_template/paper.md`
   - 受賞 → `_template/award.md`
   - 学位論文 → `_template/dissertation.md`
2. ファイル名を付ける（例 `2026robomech.md`）．**ファイル名はすべての年で重複しないようにしてください**（受賞の「関連業績」で使います）
3. `""` の間に値を書く．抄録があれば，最後の `---` の下に書く
4. push する

年のフォルダは整理用です．一覧の年タブは中身の「日付」で決まります．

## ファイルの形

```
---
タイトル: "ブリルアン光相関領域反射計によるオイラーのベルト理論の直接的可視化"
種別: "国内会議発表（ポスター）"
査読: "査読なし"
日付: "2024-05-30"
DOI: ""
---
An effective way to secure the ends of synthetic fiber ropes is ……（抄録）
```

- 先頭と最後の `---` は消さないでください．
- 1行に「項目名: "値"」を1つずつ書きます．**値は必ず `"` で囲んでください**（値の中の `"` は `\"` と書く）．
- 空欄（`""`）の項目は，ページの表に表示されません．使わない項目は行ごと消しても構いません．
- 日付は `"2024-03-22"` の形（月までなら `"2024-03"`）．
- `---` の下の本文は，表の「抄録」欄に表示されます（無ければ表示されません）．

## 項目

| 項目 | 書き方 |
|---|---|
| タイトル | |
| 種別 | `論文` / `国際会議発表` / `国内会議発表` / `解説・総説` / `著作` / `特許` / `受賞` / `学位論文` / `その他`．<br>`国内会議発表（口頭）` のように（）を付けると，（）の中が一覧の小ラベルになる |
| 査読 | `査読あり` / `査読なし`．一覧のグループ分け（例「国内会議発表（査読なし）」）に使われる |
| 著者 | 例 `杉原 怜, 遠藤 玄` |
| 言語 | `日本語` / `英語` |
| 掲載誌 | 学術誌名・会議名 |
| 巻号ページ | 例 `Vol. 92 No. 953 p. 25-00128`，講演番号のみなら `1A1-L07` |
| 日付 | 出版日（論文）・発表日（会議）・受賞日（受賞）・学位取得日（学位論文） |
| 出版社 | |
| 表彰機関 | 受賞のみ |
| 関連業績 | 受賞のみ．対象の業績のファイル名（`.md` なし．例 `2024robomech_1`）．複数なら `;` で区切る |
| DOI | `10.1299/transjsme.25-00128` の形．あれば「論文を読む」ボタンが出る |
| URL | DOI が無いときの論文ページ（IEEE Xplore など）．あれば「論文を読む」ボタンになる（受賞では学会の受賞者ページなど） |
| PDF | 本文 PDF の URL．あれば「PDFをダウンロード」ボタンが出る |

受賞に「関連業績」を書くと，**対象の業績のページの「受賞」欄にも自動で表示** されます（業績側に書く必要はありません）．

`redirect_from:` は，ファイルを年のフォルダに移す前の古い URL から転送するための行です．消さないでください（新しく作るファイルには不要です）．

## 項目を増やしたいとき

新しい項目名を使う場合は，`research/index.json` の `keys` と `tools/preview.py` の `INDEX_KEYS` に同じ名前を追加し，
`js_includes/research-data.js` の `buildItem` の `rows` に表示のしかたを追加してください．
一覧のグループの順番は `js_includes/publications.js` の `CATEGORY_ORDER` で決めています．

## 手元で確認する

リポジトリのフォルダで `python tools/preview.py` を実行し，http://localhost:4000/research.html をブラウザで開きます．
ファイルを保存してブラウザを再読み込みすれば反映されます．書き方の誤りはこのコマンドの画面に `[警告]` として出ます．
