# お知らせ（トピックス）の書き方

お知らせは **1件につき1つの .md ファイル** で，`news/` に置きます．
ファイルを追加・修正して GitHub に push すると，数分でサイトに反映されます（**HTML を書く必要はありません**）．
トップページの「トピックス」一覧にも自動で載ります（日付の新しい順）．

```
news/
├─ 20250605.md          お知らせ1件（URL は /news/20250605.html になる）
├─ 20260326-2.md        同じ日に2件目を出すときは -2 を付ける
├─ figures/             画像・動画を置く
├─ _template/           ひな形（コピーして使う．サイトには表示されない）
└─ index.json           全お知らせの一覧（GitHub Pages が自動で作る．編集しない）
```

## 追加のしかた

1. `_template/YYYYMMDD.md` をコピーし，`news/` に置く
2. ファイル名を日付にする（例 `20261106.md`）
3. 先頭の `---` で囲まれた部分（タイトル・日付）と，その下の本文を書く
4. 画像・動画は `news/figures/` に置く
5. push する

## ファイルの形

```
---
タイトル: "日本機械学会 若手優秀講演フェロー賞を受賞しました"
日付: "2025-06-05"
---
　この度，ロボティクス・メカトロニクス講演会2025において，……
```

- 先頭と最後の `---` は消さないでください．
- 「項目名: "値"」の値は必ず `"` で囲んでください（値の中の `"` は `\"` と書く）．
- 日付は `"2025-06-05"` の形．ページ上部の日付（2025.06.05）とトピックスの並び順に使われます．
- 文字コードは UTF-8（VS Code で普通に保存すれば UTF-8 になります）．

## 本文の書き方（Markdown）

`news/` と `collection/` の本文は共通です．

| やりたいこと | 書き方 |
|---|---|
| 改行 | そのまま改行する |
| 段落を分ける | 空行を1行入れる |
| 字下げ | 行頭に全角スペース `　` |
| 小見出し | `### 小見出し` |
| 太字 | `**太字**` |
| リンク | `[表示する文字](https://example.com)` |
| 箇条書き | 行頭に `- ` |
| 番号付きリスト | 行頭に `1. ` |
| 区切り線 | `---`（前後に空行） |

### 画像・動画・ボタン（1行にそれだけを書く）

前後に空行を入れて，**その行にそれだけ** を書くと，次のように表示されます．

| やりたいこと | 書き方 |
|---|---|
| キャプション付きの画像 | `![キャプション](/news/figures/20250605_figure.jpg)` |
| 幅を指定した画像 | `![キャプション](/news/figures/20250605_figure.jpg "60%")` |
| キャプション付きの動画（mp4 / webm / mov） | `![キャプション](/news/figures/20250605_movie.mp4)` |
| YouTube の埋め込み | `https://youtu.be/xxxxxxxxxxx`（URL をそのまま書く） |
| キャプション付きの YouTube | `[キャプション](https://www.youtube.com/watch?v=xxxxxxxxxxx)` |
| GitHub ボタン | `[GitHubリポジトリ - BaseNoid](https://github.com/Sugi-kmmm/BaseNoid)` |
| ボタン（その他のリンク） | `[論文詳細](/research/2026/2026jsme_paper.html)` |

- キャプションは画像の代替テキスト（alt）にもなります．
- 幅は `"60%"` や `"400px"` のように書きます（動画にも使えます）．
- 動画ファイルは GitHub の制限で **1ファイル 100MB まで**（50MB を超えると警告が出ます）．大きい動画は YouTube に上げて埋め込むのがおすすめです．
- YouTube の URL は `youtu.be/…`，`youtube.com/watch?v=…`，`youtube.com/shorts/…` のどれでも構いません．`?t=30` を付けると30秒目から再生されます．
- 文の途中に書いたリンクは，普通のリンクのままです．

### それでも HTML を書きたいとき

Markdown の中に HTML をそのまま書くこともできます（前後に空行を入れる）．

## 手元で確認する

リポジトリのフォルダで `python tools/preview.py` を実行し，表示された URL（http://localhost:4000/）をブラウザで開きます．
ファイルを保存してブラウザを再読み込みすれば反映されます．書き方の誤りはこのコマンドの画面に `[警告]` として出ます．
※ 手元の確認用の Markdown 変換は簡易版なので，本番と細部が異なることがあります．
